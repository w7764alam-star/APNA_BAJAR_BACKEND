# APNA BAZAR Backend (flat layout, phone friendly)
All files are in one folder (no sub-folders). Upload every file here to the root of your GitHub repository.
Setup: set the environment variables listed in `.env.example` (on Render: Environment tab), then
Build command: `npm install`
First start command: `npm run migrate && npm run seed && npm start`  (later: `npm start`)
See the full API list and security notes in the main backend README (apna-bazar-backend.zip).
